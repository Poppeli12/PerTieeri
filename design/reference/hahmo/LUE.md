# Per Tieerin asennot

Tallenna asentokuvat tähän kansioon näillä nimillä (PNG, valkoinen tausta, sama piirrostyyli):

| Tiedosto | Asento |
|---|---|
| `ristissa.png` | kädet ristissä edessä (nykyinen perusasento, ks. `../per-tieeri-hahmo.png`) |
| `vilkuttaa.png` | oikea käsi ylhäällä vilkuttamassa, vasen käsi vatsalla |
| `tervetuloa.png` | kädet levitettyinä sivuille, kämmenet ylöspäin (tervetuloa) |
| `sivuilla.png` | kädet suorina sivuilla |

Sen jälkeen asennot vektoroidaan samalla menetelmällä kuin perushahmo
(`scripts/vectorize-per-tieeri.py`): pää pidetään yhteisenä, jotta ilmeet, räpyttely ja
pään liike jatkuvat saumattomasti asennosta toiseen, ja vartalo vaihtuu pehmeästi.
